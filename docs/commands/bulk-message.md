# 刪除使用者訊息
> 指令：`/bulk-message <user> <time>`  
> 權限需求：`管理訊息 Manage Messages`

一次刪掉某個人最近一段時間在整個伺服器發的訊息，例如有人到處洗廣告、發詐騙連結時用來善後。

## 怎麼用

1. 輸入 `/bulk-message`，`user` 選要刪誰的訊息（可以直接貼使用者 ID，已經離開伺服器的人也可以），`time` 選範圍：10 分鐘、30 分鐘、1 小時、6 小時、12 小時、1 天、3 天、7 天、14 天
2. 機器人會逐一檢查各頻道，訊息多的話要等一下，畫面上會顯示進度
3. 檢查完會列出找到幾則、分布在哪些頻道，按「確認刪除」才會刪；不想刪就按「取消」

!!! warning "刪除後無法復原"
    名單 10 分鐘內有效，只有下指令的人可以確認或取消。檢查完之後才發的訊息不在名單裡，不會被刪到。

## 會檢查哪些地方

* 文字頻道、公告頻道、語音和舞台頻道的文字聊天
* 進行中的討論串與論壇貼文；已經封存的討論串不會檢查
* 只檢查機器人**和你**都有「管理訊息」權限的頻道，你自己碰不到的頻道不會被刪到；略過了哪些頻道，結果裡會寫出來

## 限制

* 最長只能刪 14 天內的訊息，這是 Discord 的限制
* 每個頻道最多往回檢查 10,000 則，太熱鬧的頻道可能沒檢查完，結果會標出是哪些頻道
* 同一個伺服器一次只能跑一個 `/bulk-message`

刪除結果會記在平台後台「Discord 機器人設定 → 執行紀錄」，事件名稱是「刪除訊息指令」。如果有開[伺服器紀錄](serverlog.md)，被刪掉的訊息也會照常記一筆「批次刪除訊息」。
