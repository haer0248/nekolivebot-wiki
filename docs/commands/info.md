# 查詢資訊
> 指令：`/info`  
> 權限需求：所有成員；`/info permission-check` 需要 `管理伺服器 Manage Server`

從舊機器人 haer0248.me-v3 搬過來的查詢指令。除了 `support-server` 以外，回覆都只有自己看得到。

| 指令 | 說明 |
|---|---|
| `/info user [user]` | 使用者的名稱、ID、註冊時間；在這個伺服器的話再加上暱稱、加入時間與身分組。不填就是查自己 |
| `/info server` | 伺服器的擁有者、成員人數、加成、驗證等級、建立時間等資訊 |
| `/info roles [min]` | 身分組列表與每個身分組的人數，依位階排序，一頁 20 個。填 `min` 只列出人數超過那個數字的身分組 |
| `/info emoji <emoji>` | 貼上一個自訂表情符號，查它的名稱、ID 與圖片網址 |
| `/info bot` | 機器人說明與可用指令，跟 `/help` 一樣 |
| `/info invite-url` | 機器人的邀請連結 |
| `/info permission-check` | 檢查機器人在這個伺服器缺少哪些權限、身分組位階夠不夠高，缺權限的話附上重新邀請的按鈕 |
| `/info support-server` | 客服中心與社群伺服器連結，這個回覆所有人都看得到，方便直接貼給別人 |

!!! tip "人數第一次查會比較慢"
    `/info roles` 要先讀取整個伺服器的成員才算得出人數，成員多的伺服器第一次會等幾秒，之後 2 分鐘內再查會很快。
