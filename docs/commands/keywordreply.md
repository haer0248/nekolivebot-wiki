# 關鍵字回應
> 設定：[網頁控制台](../dashboard.md)「關鍵字回應」，或平台後台「Discord 機器人設定 → 模組設定 → 關鍵字回應」  
> 權限需求：`管理伺服器 Manage Server`

成員發的訊息符合你設定的關鍵字時，機器人自動回覆。用法跟 Nekolive 的 Twitch 自訂指令一樣，也可以直接從 Twitch 匯入。這個功能沒有斜線指令，全部在網頁上設定。

## 總開關

用 `/settings enable|disable keyword_reply` 控制（見[群組功能開關](settings.md)），預設為**未啟用**。網頁上方的「啟用關鍵字回應」開關也是同一個。

## 每個關鍵字可以設定什麼

| 設定 | 說明 |
|---|---|
| 關鍵字、別名 | 關鍵字最多 100 字，別名最多 10 個 |
| 比對方式 | 指令（第一個字相同）、整則訊息相同、訊息開頭是、訊息包含 |
| 回應 | 最多 2000 字，可以放下面的參數與函式 |
| 回應方式 | 回覆那則訊息，或直接發在頻道 |
| 誰可以使用 | 所有人、指定身分組（最多 25 個）、有「管理訊息」權限的人、有「管理伺服器」權限的人 |
| 限定頻道 | 只在選的頻道回應（最多 50 個），不選就是全部頻道 |
| 冷卻 | 全體冷卻與個人冷卻，0～86400 秒 |
| 無法使用時的回應 | 冷卻中、沒有權限時要不要回一句話，最多 500 字 |

一個伺服器最多 300 個關鍵字。

## 參數

| 參數 | 內容 |
|---|---|
| `{user_name}` | 成員在伺服器顯示的名稱 |
| `{user_login}` | 成員的使用者名稱 |
| `{mention}` | 標記發訊息的成員 |
| `{count}` | 使用次數（當下會加一） |
| `{input}` | 關鍵字後面接的文字 |
| `{channel}` | 目前的頻道 |
| `{server}` | 伺服器名稱 |
| `{member_count}` | 伺服器成員人數 |
| `{chatters}` | Twitch 聊天室人數（要綁定 Twitch） |

`rand()`、`draw()`、`roll_gun()`、`fetch()`、`eval()` 這些函式也能用，寫法跟 Twitch 自訂指令一樣。`roll_gun()` 中彈的成員會在 Discord 被禁言。

## 有綁定 Twitch 的話

伺服器[綁定的 Nekolive 創作者帳號](nekolive.md)有綁 Twitch 時，還可以：

* 限制只能在 Twitch 直播中使用、整場次數上限、每人次數上限
* 限定直播分類（最多 10 個），只有在播這些分類時才會回應
* 用關鍵字操作直播：開關排隊、改直播標題與分類、控制計時器和媒體點播、管理點歌、建立 Twitch 剪輯

!!! note "操作直播的關鍵字只有管理員能用"
    開關排隊、改標題、控制點歌這類操作，不管「誰可以使用」選什麼，都只有「管理訊息」以上的成員能觸發。

## 從 Twitch 匯入

按頁面下方的「從 Twitch 匯入」，可以把 Twitch 機器人的自訂指令複製過來，已經有同樣關鍵字的不會重複匯入。匯入之後兩邊各自獨立，不會自動同步。

以下指令要用觀眾自己的 Twitch 帳號才能做，Discord 不能用，匯入時會先停用並標出原因：

* 簽到、簽到查詢、Vip 查詢
* 媒體點播、音樂播放器點播
* 加入、離開、查詢排隊
* 點數查詢、排行榜、互轉點數與點數小遊戲

只限訂閱者或 Vip 的指令，要改成「指定身分組」再開啟。
