# 邀請連結偵測
> 指令：`/inviteguard`  
> 權限需求：`管理伺服器 Manage Server`

抓「貼違規伺服器邀請連結」的人，例如 Nitro 詐騙伺服器、18+／NSFW 伺服器的宣傳。

## 怎麼判斷違規

這個功能是**全域**的：所有有 NekoliveBot 的伺服器，只要有人貼 Discord 邀請連結，機器人都會幫那個邀請碼累計一次。

1. 同一個邀請碼累計到{==第 5 次==}，機器人才會向 Discord 查詢目標伺服器的名稱（不會每個連結都查）
2. 符合下面任一條件就判定為違規：
    * 伺服器名稱同時有 free 和 nitro（Nitro 詐騙）
    * 伺服器名稱有 18+、NSFW、porn、nudes、leaks 等字眼
    * Discord 把這個伺服器標記為成人內容
    * 同一個伺服器的其他邀請已經被判定違規
3. 判定違規之後，**有開這個功能的伺服器**有人再貼這個邀請，就會依設定處理

就算你的伺服器沒有開這個功能，邀請連結一樣會被累計，幫其他伺服器更快抓到違規邀請。機器人只記錄邀請碼和出現次數，不會記錄是誰貼的。

!!! tip "不會被處理的情況"
    * 擁有「管理伺服器」權限的成員與伺服器擁有者
    * 貼的是自己伺服器的邀請
    * 頻道名稱有「廣告」「宣傳」「自宣」「partner」「promo」的頻道（本來就是讓人貼邀請的地方）

## 總開關

用 `/settings enable|disable invite_guard` 控制（見[群組功能開關](settings.md)），預設為**未啟用**。

## 指令

* `/inviteguard config [action] [delete_message] [timeout_minutes] [notify_owner]`：調整設定，所有選項為選填
* `/inviteguard status`：查看目前設定
* `/inviteguard lookup <invite>`：查詢某個邀請目前的判定、出現次數與目標伺服器

## 提供設定選項

| 選項 | 說明 | 預設 |
|---|---|---|
| `action` | 處理動作：不處理、禁言、踢出、封鎖（四選一） | 不處理 |
| `delete_message` | 要不要刪除那則訊息 | 開啟 |
| `timeout_minutes` | 禁言分鐘數，`action` 設成禁言時使用 | 60 分鐘 |
| `notify_owner` | 要不要私訊通知群組擁有者 | 開啟 |

偵測到時，機器人會先私訊貼連結的人說明原因，再刪訊息、執行處理動作，並寫一筆進平台後台的執行紀錄。

## 覺得被誤判？

邀請的判定是所有伺服器共用的，只有機器人管理員能手動調整。如果你的伺服器被誤判，請到[客服中心](https://help.nekolive.net/){:target="_blank"}回報。
