# 建立 Webhook
> 指令：`/webhook`  
> 權限需求：`管理伺服器 Manage Server`

`/webhook channel <channel>`：在指定的文字頻道（或公告頻道）建立一個 Webhook，供開台通知等用途使用。

## 使用流程

1. 執行 `/webhook channel` 並選擇頻道
2. 機器人會跳出確認訊息，{==30 秒內按「確定」才會建立==}，逾時或按「取消」都不會建立
3. 建立完成後，機器人會回覆 Webhook 網址，請把這個網址貼回指定輸入框。

!!! danger "請不要把 Webhook 網址分享到公開頻道"
    拿到這個網址的人都能用它發訊息到你的頻道。若需要刪除 Webhook，請到 **伺服器設定 → 整合 → Webhook** 進行。

## 注意事項

* 只能選擇文字頻道或公告頻道，其他類型的頻道（語音、論壇等）不能建立
