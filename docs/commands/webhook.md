# 建立 Webhook
> 指令：`/webhook`  
> 權限需求：`管理伺服器 Manage Server`

在指定的文字頻道（或公告頻道）建立一個 Webhook，網址貼到 Nekolive 平台的直播通知、影片上傳通知設定。

由機器人建立的 Webhook 才能在通知裡放「觀看直播」這類按鈕，自己在 Discord 建立的 Webhook 沒辦法。

## 三種建立方式

### 在平台的通知設定頁直接建立（最方便）

Twitch／Kick／YouTube 機器人的「直播通知」、YouTube 的「影片上傳通知」頁，Webhook 網址欄位旁有 **建立 Webhook** 按鈕：

1. 按「建立 Webhook」，選擇要發送通知的頻道
2. 網址會自動填進欄位，再按「儲存」就完成了

需要先在平台的 **Discord 機器人 → 群組設定** 綁定伺服器，Webhook 會建在綁定的伺服器裡。要建在其他伺服器，請用下面的指令。

### 在網頁控制台建立

[網頁控制台](../dashboard.md) 的 **建立 Webhook** 頁：選頻道 → 建立，網址會顯示在頁面上，按「複製」再貼到平台的通知設定。不需要平台帳號，你有「管理伺服器」權限的伺服器都能用。

### 用指令建立

`/webhook channel <channel> [new]`

1. 執行 `/webhook channel` 並選擇頻道
2. 機器人會跳出確認訊息，{==30 秒內按「確定」才會建立==}，逾時或按「取消」都不會建立
3. 建立完成後，機器人會回覆 Webhook 網址（只有你看得到），請把這個網址貼回平台的通知設定

## 會一直多出新的 Webhook 嗎？

不會。頻道裡已經有機器人建立的 Webhook 時，三種方式都會直接沿用那一個，拿到的是同一個網址。Discord 每個頻道最多只能有 15 個 Webhook。

舊網址外流、想換一個新網址時，指令加上 `new:True`，或在平台、網頁控制台打開「另外建立新的 Webhook」。舊的那個請自己到 Discord 刪除。

!!! danger "請不要把 Webhook 網址分享到公開頻道"
    拿到這個網址的人都能用它發訊息到你的頻道。若需要刪除 Webhook，請到 **伺服器設定 → 整合 → Webhook** 進行。

## 注意事項

* 只能選擇文字頻道或公告頻道，其他類型的頻道（語音、論壇等）不能建立
* 機器人在那個頻道需要 **檢視頻道** 與 **管理 Webhook** 權限，缺權限的頻道在平台和網頁控制台會標示出來、不能選
