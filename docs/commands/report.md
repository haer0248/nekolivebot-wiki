# 檢舉功能
> 指令：`/report`  
> 權限需求：`無`

* 指令：`/report user <user>` — 選好要檢舉的使用者後，會跳出表單填寫原因
* 右鍵選單：在使用者身上按右鍵 → 應用程式 → NekoliveBot → 檢舉此使用者。一樣跳出表單填寫原因

!!! question "為什麼要先選人才能填原因"
    Discord 的表單目前不支援放「使用者選單」，所以「選人」這一步是在叫出表單**之前**完成的（指令的使用者選項，或右鍵選單本身鎖定的目標），表單本身只負責收「原因」這一個欄位。

## 送出後會發生什麼事

送出後，平台管理員將會進行核查，若資料及原因屬實，我們將會列入黑名單，日後管理員可使用 `/blacklist check <user_id>` 檢查該名使用者狀態。

!!! danger "警告"
    濫用檢舉功能的使用者會被加入回報黑名單。
