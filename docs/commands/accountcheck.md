# 可疑帳號偵測
> 指令：`/accountcheck`  
> 權限需求：`管理伺服器 Manage Server`

新成員加入群組時，依規則判斷是不是疑似機器人、自動化帳號，符合就通知群組擁有者，並可選擇自動禁言、踢出、封鎖。

!!! warning "預設未啟用"
    跟其他既有功能不同，這個功能需要用 `/settings enable suspicious_account` 主動開啟才會生效（見[群組功能開關](settings.md)）。

## 偵測規則

| 規則 | 說明 |
|---|---|
| 帳號建立時間 | 帳號建立未滿指定天數（預設 7 天）視為可疑 |
| 頭貼是否為預設 | 沒設過自訂頭貼視為可疑 |
| 個人資料、狀態是否為空 | 沒有自訂動態（狀態列文字）、沒有自訂橫幅、也沒有個人資料顏色，視為可疑 |

## 指令

* `/accountcheck config`：設定規則開關、門檻、觸發條件、處理動作
* `/accountcheck status`：查看目前設定
* `/accountcheck whitelist add|remove|list`：管理白名單（見下方）

### 提供設定選項

| 選項 | 說明 | 預設 |
|---|---|---|
| `check_account_age` / `min_account_age_days` | 是否檢查帳號建立時間、門檻天數 | 開啟 / 7 天 |
| `check_default_avatar` | 是否檢查預設頭貼 | 開啟 |
| `check_empty_profile` | 是否檢查個人資料為空 | 開啟 |
| `match_mode` | `all`=符合全部已啟用的規則才觸發（較保守）／`any`=符合任一就觸發（較激進，容易誤判） | `all` |
| `action` | 觸發時的處理動作：不處理、禁言、踢出、封鎖 | 不處理 |
| `timeout_minutes` | 禁言分鐘數 | 10 分鐘 |
| `notify_owner` | 是否私訊通知群組擁有者 | 開啟 |

這是機率性判斷，新帳號、預設頭貼、空白個人資料，真人新使用者也可能符合，所以預設動作是「不處理，只通知」，需要你自己觀察一陣子、評估誤判率之後，再決定要不要調高處置力道。

!!! tip "自動處理前會先私訊當事人"
    如果設定了自動禁言、踢出、封鎖，執行前機器人會先私訊當事人，說明「帳號被系統標記為可疑並自動處理」，並附上「如果你是真人，很抱歉造成不便」的道歉與建議（自訂頭貼、個人資料後可以再重新加入）。

## 白名單

* `/accountcheck whitelist add user_id:<Discord 使用者 ID> reason:<原因，選填>`  
把某個使用者永久加入這個群組的白名單，之後他加入時會完全略過這段偵測（不評估規則、不通知、不執行任何動作）。  
適合管理員自己的分身帳號、已經人工確認過的真人成員等固定會被誤判的對象。

* `/accountcheck whitelist remove user_id:<ID>`：移出白名單
* `/accountcheck whitelist list`：查看目前白名單

白名單是**每個群組各自管理**，不是跨群組共用（跟的[全域黑名單](blacklist.md)相反）。
