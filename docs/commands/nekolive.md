# 綁定 Nekolive 創作者帳號
> 指令：`/nekolive link <code>`  
> 權限需求：`管理伺服器 Manage Server`

把伺服器綁到 Nekolive 創作者帳號之後，平台後台的「Discord 機器人設定」「同步 Discord 身分組」才知道要管哪一個伺服器。

## 怎麼綁定

1. 到 Nekolive 後台「Discord 機器人設定 → 群組設定」或「同步 Discord 身分組 → 同步設定」，按「綁定伺服器」取得 8 碼代碼
2. 在要綁定的伺服器輸入 `/nekolive link code:代碼`
3. 回到後台頁面，綁好後會自動更新

* 代碼 10 分鐘內有效，用一次就失效；重新產生的話，舊的代碼會作廢
* 代碼不分大小寫，中間的空格、連字號可以不打
* 同一個人 10 分鐘內輸入錯誤 5 次，要等 10 分鐘才能再試
* 一個創作者帳號只會綁定一個伺服器，在另一個伺服器輸入新的代碼，就會改綁到那個伺服器

!!! info "也可以用伺服器 ID 綁定"
    後台也可以直接貼伺服器 ID 綁定，這種方式需要先在 Nekolive 綁定 Discord 帳號，而且你要是那個伺服器的擁有者或管理員。
