# 好玩的指令
> 指令：`/http`、`/minecraft`  
> 權限需求：所有成員

## HTTP 狀態碼圖片：`/http cat|dog <code>`

輸入 100～599 的 HTTP 狀態碼，機器人會貼出對應的貓咪（`cat`）或狗狗（`dog`）圖片，所有人都看得到。同一個人 30 秒內只能用一次；沒有那張圖的狀態碼會用只有自己看得到的訊息提示。

## Minecraft 查詢：`/minecraft username|server <input>`

* `username`：輸入玩家名稱，查是不是正版帳號與 UUID
* `server`：輸入伺服器位址，查即時狀態；不是預設連接埠 25565 的話要加上連接埠，例如 `mc.example.com:25570`

查不到資料跟查詢失敗會分開提示。
