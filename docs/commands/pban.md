# 手動封鎖
> 指令：`/pban`、`/punban`  
> 權限需求：`封鎖成員 Ban Members`

舊機器人 `/punish ban`、`/punish unban` 的新版。

## 封鎖：`/pban <user> [days] [reason]`

| 選項 | 說明 | 預設 |
|---|---|---|
| `user` | 要封鎖的人，可以直接貼使用者 ID，不在伺服器裡的人也能先封鎖 | 必填 |
| `days` | 一併刪除幾天內的訊息，0～7 | 7 |
| `reason` | 封鎖原因，會寫進 Discord 的審核日誌，並附上是誰下的指令 | 未填寫 |

封鎖成功後，機器人會在下指令的頻道公開貼一則通知。

以下情況不能封鎖：

* 自己、機器人自己、伺服器擁有者
* 已經在封鎖名單裡的人
* 身分組位階跟你一樣或比你高的成員（伺服器擁有者下指令不受這個限制）
* 身分組位階跟機器人一樣或比機器人高的成員，請到 **伺服器設定 → 身分組** 把機器人往上拖

## 解除封鎖：`/punban <userid> [reason]`

`userid` 有自動完成，輸入名稱或 ID 的一部分，就能直接從封鎖名單挑。解除原因一樣會寫進審核日誌。

!!! tip "只想刪訊息、不想封鎖"
    用 [`/bulk-message`](bulk-message.md) 刪掉某個人最近一段時間發的訊息。
