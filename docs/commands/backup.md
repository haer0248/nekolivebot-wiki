# 伺服器結構備份
> 指令：`/backup`  
> 權限需求：`管理員 Administrator`

備份伺服器的**結構**：類別、各類頻道（含主題、慢速模式、位元率與權限覆寫）、身分組（含顏色、權限、是否分開顯示）。

用途是有人——可能是被盜用的管理員帳號、或是被加進來的惡意機器人——把頻道或身分組刪光時，可以把架構長回來。

!!! danger "訊息內容無法備份"
    Discord 沒有提供讓機器人備份訊息的 API。頻道被刪掉之後，{==裡面的訊息就是永久消失==}，這個功能只能還原架構與權限設定，不能把對話救回來。

## 總開關

自動備份要不要執行，是用 `/settings enable|disable server_backup` 控制（見[群組功能開關](settings.md)），預設為**未啟用**。

關閉時仍然可以用 `/backup create` 手動備份，只是機器人不會主動幫你存。

## 指令

* `/backup create [note]`：立即備份目前結構，`note` 是給自己看的備註
* `/backup list`：查看備份清單
* `/backup show <id>`：查看某份備份裡有哪些頻道與身分組
* `/backup restore [id]`：依備份還原，不填 `id` 就用最新一份

`restore` 會先跳出確認按鈕，按下「確定還原」才會真的開始。

## 自動備份的兩種時機

| 時機 | 說明 |
|---|---|
| 定期備份 | 每天跑一次。結構沒有變動就不會重複存，所以平常只會在真的有人調整過頻道／身分組之後多一筆。 |
| 刪除當下備份 | 偵測到頻道或身分組被刪除時，立刻存一份。 |

!!! tip "「刪除當下」存的是刪除前的結構"
    這是這個功能最關鍵的地方。事件發生的瞬間，機器人手上其他頻道的資料都還在，再把剛被刪掉的那個補回去，組出來的就是{==刪除前==}的完整結構，不是刪完之後的殘骸。  
    整個伺服器被大量刪除時有 5 分鐘冷卻，只會存第一份（那份已經包含被清空前的完整結構）並通知擁有者一次，不會被灌爆。

每個伺服器保留最近 15 份快照，其中「刪除前自動備份」另外多保留 3 份，因為那是最關鍵的。

## 還原規則

還原採**只增不刪**：

* 只會補回目前不存在的類別、頻道與身分組，{==不會刪除或覆蓋現有的東西==}。
* 名稱相同的頻道／身分組視為已存在，會直接跳過，所以重複按還原不會一直長出同名頻道。
* 身分組會先還原，再還原頻道。因為頻道的權限覆寫指向身分組，新建立的身分組編號跟快照裡的不一樣，機器人會自動對應回去。
* 已經離開伺服器的成員，他們的個別頻道權限留著也沒意義，會略過。

!!! warning "還原後要自己調整身分組位階"
    新建立的身分組位階會在機器人的身分組之下，順序可能跟原本不一樣，請到 **伺服器設定 → 身分組** 自己拖回正確位置。成員也需要重新指派身分組。

數量多的時候 Discord 會限速，還原可能要跑上一段時間。單次還原有建立數量上限，達到上限時機器人會提示你再執行一次補完剩下的。

## 在平台後台操作

除了指令之外，也可以在 Nekolive 平台後台的 **Discord 機器人設定 → 伺服器備份** 查看備份清單、手動備份、預覽某份備份裡的頻道與身分組，以及直接還原。
