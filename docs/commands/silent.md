# 私密轉送
> 指令：`/silent send`（所有成員）、`/silent-setup`（`管理伺服器 Manage Server`）

成員用 `/silent send`，或按匿名訊息下方的「發送訊息」按鈕打開表單輸入訊息，機器人會用「🔏 匿名訊息」的形式發到管理員指定的頻道，頻道裡看不出是誰傳的。適合匿名投稿、意見箱、告白牆。

!!! warning "頻道裡匿名，但後台查得到"
    為了防止騷擾或濫用，傳送者會記在平台後台的「執行紀錄 → 功能紀錄」，只有能進後台的人看得到。表單裡也會老實告訴成員這件事。

## 總開關

用 `/settings enable|disable silent` 控制（見[群組功能開關](settings.md)），預設為**啟用**，但要先用 `/silent-setup channel` 設定轉送頻道才會有作用。

## 成員怎麼用

1. 在伺服器任何地方輸入 `/silent send`，或在轉送頻道按任何一則匿名訊息下方的「發送訊息」
2. 在跳出的表單輸入訊息，也可以附上圖片（PNG、JPG、GIF、WebP，每張 8MB 以內）；訊息和圖片至少要有一個。字數上限、能不能附圖、最多幾張由管理員設定（預設 2000 字、可以附 4 張）
3. 送出後會收到一則只有自己看得到的回覆，附上訊息連結

訊息裡的 @ 標記不會通知任何人，避免被拿來匿名騷擾。圖片會由機器人重新上傳、檔名換成 image-1 這類名稱，看不出原本是誰傳的。

## 管理員設定

* `/silent-setup channel <channel>`：設定轉送頻道
* `/silent-setup cooldown <seconds>`：同一位成員兩次轉送之間要隔幾秒，`0` 代表不限制（預設 60 秒）
* `/silent-setup status`：查看目前設定
* `/silent-setup disable`：清除轉送頻道，成員就不能再用 `/silent send`

擁有「管理伺服器」權限的成員不受冷卻限制。

## 樣式與限制

在平台後台「模組設定 → 私密轉送」或[網頁控制台](../dashboard.md)設定：

| 設定 | 說明 | 預設 |
|---|---|---|
| 顯示樣式 | Embed 卡片或純文字 | Embed 卡片 |
| Embed 卡片 | 顏色、標題、內容、欄位、圖片、頁尾都可以改，旁邊有預覽 | 「🔏 匿名訊息」卡片 |
| 純文字內容 | 純文字樣式時送出的文字 | `**🔏 匿名訊息**` 加上訊息 |
| 訊息字數上限 | 1～2000 字 | 2000 |
| 可以附圖片 | 關掉的話表單不會出現上傳欄位 | 開啟 |
| 最多幾張圖片 | 1～4 張 | 4 |
| 「發送訊息」按鈕 | 匿名訊息下方要不要放按鈕 | 開啟 |

卡片和純文字都可以用這些參數：

| 參數 | 內容 |
|---|---|
| `{message}` | 成員送出的訊息 |
| `{number}` | 投稿編號（這個伺服器第幾則匿名訊息） |
| `{server}` | 伺服器名稱 |
| `{channel}` | 轉送頻道名稱 |

純文字樣式一定要放 `{message}`。附一張圖片會放在卡片的大圖，多張會排成圖片牆；純文字樣式的圖片接在文字下面。

機器人在轉送頻道需要「檢視頻道」「發送訊息」「嵌入連結」「附加檔案」權限。
