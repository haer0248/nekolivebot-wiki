# 通知對象
> 指令：`/notification`  
> 權限需求：`管理伺服器 Manage Server`

洗版偵測、誘餌頻道、黑名單、自動懲處、邀請連結偵測、大量標記偵測、可疑帳號偵測與伺服器備份失敗的通知，預設都私訊伺服器擁有者。不想全部丟給擁有者的話，可以改成私訊指定的人，或發到管理員頻道並標記身分組。

## 指令

| 指令 | 說明 |
|---|---|
| `/notification owner` | 私訊伺服器擁有者（預設） |
| `/notification users <user1> [user2] … [user5]` | 私訊指定的使用者，最多 5 位，例如擁有者加上幾位管理員 |
| `/notification channel <channel> [role]` | 發到頻道，`role` 填了會一併標記那個身分組 |
| `/notification status` | 查看目前通知送給誰 |
| `/notification test` | 送一則測試通知，確認收得到 |

平台後台「Discord 機器人設定 → 模組設定 → 通知對象」與[網頁控制台](../dashboard.md)也可以設定，三邊改的是同一份。

## 注意事項

* 私訊的對象要在伺服器裡，而且要開「允許來自伺服器成員的私訊」才收得到
* 發到頻道時，機器人在那個頻道需要「檢視頻道」「發送訊息」權限
* 要標記的身分組要開「允許任何人 @提及這個身分組」，或機器人有「提及 @everyone、@here 和所有身分組」權限，不然通知會發出去但不會標記到
* 送不出去的時候（對方關了私訊、頻道被刪掉或機器人沒權限），會改私訊伺服器擁有者，不會漏掉

!!! info "有處理按鈕的通知"
    黑名單使用者加入時的通知有「禁言」「踢出」「封鎖」「忽略」按鈕。發到頻道的話，只有對應權限的人按得動（禁言成員、踢出成員、封鎖成員，「忽略」是三個任一個）；私訊的話，收到的人就能按。

各功能裡的「通知」開關一樣有效，關掉的功能不會發通知。
