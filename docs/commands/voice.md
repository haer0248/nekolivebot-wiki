# 動態語音頻道
> 指令：`/voice`  
> 權限需求：頻道擁有者；`/voice default` 需要 `管理伺服器 Manage Server`

設一個「入口」語音頻道，成員一加入，機器人就會在同一個類別底下開一個屬於他的語音頻道，並把他移過去。頻道裡沒有人時會自動刪除。

開頻道的人就是這個頻道的**擁有者**，可以用 `/voice` 改名、限制人數、切換公開或私人、邀請或踢出成員。

## 總開關

功能本身要不要執行，是用 `/settings enable|disable dynamic_voice` 控制（見[群組功能開關](settings.md)），預設為**啟用**，但要先用 `/voice default enter` 設定入口頻道才會有作用。

關閉之後就不會再開新頻道，已經開出來的頻道還是會在沒有人時自動刪除。

## 管理員設定

> 權限需求：`管理伺服器 Manage Server`

* `/voice default enter <channel>`：設定入口語音頻道
* `/voice default name <name>`：新頻道的預設名稱
* `/voice default limit <limit>`：新頻道的預設人數上限
* `/voice default public <value>`：新頻道預設公開或私人
* `/voice default text <value>`：開語音頻道時要不要順便開一個文字頻道
* `/voice default text-name <name>`：動態文字頻道的預設名稱
* `/voice default status`：查看目前設定，並檢查機器人權限

| 選項 | 說明 | 預設 |
|---|---|---|
| `enter` | 成員加入這個語音頻道就會自動開新頻道，新頻道會開在同一個類別 | 未設定 |
| `name` | 可以用 `{name}` 代入成員在伺服器顯示的名稱，最多 100 字 | `{name} 的頻道` |
| `limit` | `0`～`99`，`0` 代表不限 | 不限 |
| `public` | `True` 公開、`False` 私人 | 公開 |
| `text` | `True` 一起開文字頻道、`False` 只開語音頻道 | 不開 |
| `text-name` | 動態文字頻道的名稱，一樣可以用 `{name}`，最多 100 字 | `{name} 的文字頻道` |

每次設定完，機器人都會回覆目前的完整設定，並一起檢查權限夠不夠。

!!! warning "機器人需要的權限"
    動態語音頻道需要機器人有「管理頻道」、「管理身分組」與「移動成員」權限，而且要看得到、連得進入口頻道。  
    這幾項{==不在其他功能需要的權限裡==}，`/honeypot check` 的重新邀請按鈕也不會補上，請另外到 **伺服器設定 → 身分組** 確認。`/voice default status` 會直接列出缺哪一項。

## 頻道擁有者指令

> 權限需求：頻道擁有者

* `/voice name <name>`：改名，一樣可以用 `{name}`
* `/voice public <value>`：`True` 公開、`False` 私人
* `/voice invite <user>`：邀請成員，私人頻道也能進入
* `/voice limit <limit>`：人數上限，`0` 代表不限
* `/voice kick <user>`：把成員踢出頻道，對方之後也不能再加入
* `/voice set-owner <user>`：把擁有者轉給頻道裡的另一位成員

在自己的頻道裡下指令，就會套用到這個頻道；不在頻道裡也能下，會套用到你開的那一個。在別人的頻道裡下指令，機器人會告訴你擁有者是誰。

!!! info "一個人只會有一個頻道"
    已經有頻道的人再進入口，會被直接移回自己的頻道，不會再開一個新的。  
    `/voice set-owner` 的對象也不能已經有自己的頻道。

!!! tip "要先離開的話，記得把頻道交出去"
    擁有者離開頻道之後，頻道還是歸他管，留下來的人沒辦法改設定。要先走的話，先用 `/voice set-owner` 把頻道交給還在裡面的人。

## 公開與私人

| 狀態 | 誰看得到、能加入 |
|---|---|
| 公開 | 跟類別的權限設定一樣 |
| 私人 | 擁有者、被邀請的人，以及有管理員權限的人 |

私人頻道沒被邀請的人{==看不到==}，頻道裡的文字聊天（不管是內建的語音頻道文字聊天，還是動態文字頻道）也讀不到。想加入的話請擁有者用 `/voice invite` 邀請。

公開改成私人的時候，當下在頻道裡的人會自動加進邀請名單，不會被踢出去。

被邀請的人會被標記（有動態文字頻道就在那裡，沒有就在語音頻道的文字聊天），點一下就能加入。

!!! tip "踢出之後想讓對方回來"
    `/voice kick` 會把對方移出頻道，並禁止他再加入，公開頻道也一樣。想讓他回來，再用 `/voice invite` 邀請一次就好。

## 動態文字頻道

> 預設不開，用 `/voice default text True` 或平台後台開啟。

開啟後，成員開語音頻道時，機器人會在同一個類別順便開一個文字頻道給他，方便貼連結、留言。不開的話，成員一樣可以用 Discord 內建的語音頻道文字聊天。

文字頻道全部跟著語音頻道走：

* 公開／私人一起切換，私人時只有擁有者和被邀請的人看得到
* `/voice invite`、`/voice kick`、`/voice set-owner` 一起套用（被踢出的人看不到文字頻道）
* `/voice name` 改名時一起改
* 語音頻道沒人、被刪除時一起刪除；只刪文字頻道的話，語音頻道照常運作

動態文字頻道一樣不會被[伺服器結構備份](backup.md)備份進去。

## 頻道權限

新頻道的權限會照入口頻道所在類別的設定，再加上擁有者與機器人自己的權限。

類別裡如果有機器人自己沒有的權限，Discord 不允許機器人照抄，那幾項會被略過。`/voice default status` 會列出是哪幾項，要完全一樣的話，請給機器人這些權限或管理員權限。

## 什麼時候會自動刪除

頻道裡**沒有真人**時就會刪除，只剩音樂機器人之類的 bot 也算沒有人。成員直接離開伺服器、被踢出或封鎖，也會一起判斷。

機器人重新啟動或暫時斷線的期間，如果頻道剛好空了，重新上線後會在幾分鐘內補刪；這段時間待在入口頻道的人，也會補開頻道給他。

動態頻道不算伺服器結構，[伺服器結構備份](backup.md)不會把它們存進去，被刪除時也不會觸發「刪除前自動備份」。

!!! note "改名次數限制"
    Discord 限制一個頻道的名稱 10 分鐘內只能改 2 次，超過時機器人會告訴你什麼時候可以再改。

## 在平台後台操作

入口頻道與新頻道的預設值，也可以在 Nekolive 平台後台的 **Discord 機器人設定 → 動態語音頻道** 修改。入口頻道請填頻道 ID，留空就是停用。
