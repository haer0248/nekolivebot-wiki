# 抽獎
> 指令：`/giveaway`  
> 權限需求：`管理伺服器 Manage Server`（參加抽獎不需要任何權限）

在頻道發一則抽獎訊息，成員按「參加抽獎」就能報名，時間到機器人會自動開獎、標記得獎者。

## 舉辦抽獎

1. 輸入 `/giveaway start`，下面三個選項都可以不填：
    * `winners`：抽出幾位，預設 1 位，最多 20 位
    * `channel`：抽獎訊息發在哪個頻道，預設是現在這個頻道
    * `min_days`：加入伺服器滿幾天才能參加，防止有人開小號來抽
2. 送出後會跳出表單：
    * **獎品**：必填
    * **多久後開獎**：例如 `30m`、`2h`、`1d12h`，也可以寫 `1天`、`3小時`，最短 1 分鐘、最長 30 天
    * **說明**：選填，會顯示在獎品下面
    * **限定身分組**：選了的話，要有其中一個身分組才能參加
    * **排除身分組**：有其中一個身分組就不能參加，例如排除管理員或上次得獎的人
3. 機器人會把抽獎訊息發到頻道，上面寫著開獎時間、得獎人數、參加人數與參加資格

!!! info "機器人需要的權限"
    在抽獎頻道需要「檢視頻道」「發送訊息」「讀取訊息歷史」。

## 參加抽獎

成員按抽獎訊息下方的「🎉 參加抽獎」就報名了，回覆只有自己看得到。不符合資格時會說明原因，例如少了哪個身分組，或是還要幾天才能參加。報名後按回覆裡的「退出抽獎」可以退出。

## 開獎

時間到機器人會自動開獎，機器人重新啟動也不會漏掉：

* 從參加的人裡面隨機抽，已經離開伺服器或開獎時不再符合資格的人會跳過
* 符合資格的人比得獎人數少時，就只抽出符合資格的人
* 抽獎訊息會改成得獎名單，另外回覆一則訊息標記得獎者

## 管理抽獎

| 指令 | 說明 |
|---|---|
| `/giveaway end <id>` | 不等時間到，馬上開獎 |
| `/giveaway reroll <id> [count]` | 從還沒中獎的參加者重新抽，`count` 是抽幾位（預設 1 位），例如得獎者聯絡不到時用 |
| `/giveaway cancel <id>` | 取消抽獎，不會抽出得獎者 |
| `/giveaway list` | 列出報名中與最近結束的抽獎 |

`id` 打字時會自動列出可以選的抽獎，不用自己記編號。同一個伺服器最多 20 場抽獎同時報名。

開獎、重抽、取消都會記在平台後台「Discord 機器人設定 → 執行紀錄」的「功能」分類，事件名稱是「抽獎」。
