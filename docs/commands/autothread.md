# 自動討論串
> 指令：`/autothread`  
> 權限需求：`管理伺服器 Manage Server`

在指定的頻道發訊息，機器人就會用那則訊息自動開一個討論串，適合提問區、作品分享區、許願池這類「一則訊息一個話題」的頻道。

原訊息、附件、作者都會保留，討論串直接掛在原訊息底下。

## 總開關

用 `/settings enable|disable auto_thread` 控制（見[群組功能開關](settings.md)），預設為**啟用**，但要先用 `/autothread add` 設定頻道才會有作用。

## 指令

* `/autothread add <channel> [title] [message] [cooldown] [archive]`：新增頻道，或修改已經設定的頻道（沒填的欄位維持原設定）
* `/autothread remove <channel>`：這個頻道不再自動開討論串
* `/autothread list`：列出所有設定的頻道

一個伺服器可以設定多個頻道，每個頻道各自有自己的標題與規則。平台後台「模組設定 → 自動討論串」也可以設定。

## 提供設定選項

| 選項 | 說明 | 預設 |
|---|---|---|
| `title` | 討論串標題，`{name}` 會換成成員名稱、`{content}` 會換成訊息開頭 50 字 | `{name} 的討論串` |
| `message` | 討論串開好後，機器人先在裡面發的開頭訊息。`{user}` 會標記發訊息的人，`\n` 換行；填 `none` 代表不發 | 不發 |
| `cooldown` | 同一位成員在這個頻道開討論串的間隔秒數，`0` 代表不限制 | 0 |
| `archive` | 多久沒人說話自動封存：1 小時、1 天、3 天、7 天 | 1 天 |

!!! info "冷卻中發的訊息會被刪掉"
    有設定冷卻時間的話，冷卻中發的訊息會被刪除，機器人會私訊告訴他還要等多久，並附上剛剛的訊息內容，方便他之後再貼一次。  
    擁有「管理伺服器」權限的成員不受冷卻限制。

## 需要的權限

機器人在這個頻道需要「檢視頻道」「建立公開討論串」「在討論串中傳送訊息」；有設定冷卻的話，還需要「管理訊息」才能刪除冷卻中的訊息。
