# 資訊顯示頻道
> 設定：[網頁控制台](../dashboard.md)「資訊顯示頻道」，或平台後台「Discord 機器人設定 → 模組設定 → 資訊顯示頻道」  
> 權限需求：`管理伺服器 Manage Server`

機器人會在伺服器開只能看、不能進的語音頻道，用頻道名稱顯示現在有沒有在直播，以及伺服器人數。這個功能沒有斜線指令，全部在網頁上設定。

## 總開關

用 `/settings enable|disable info_channels` 控制（見[群組功能開關](settings.md)），預設為**未啟用**。

## 可以顯示什麼

每一項都可以各自打開或關掉，頻道名稱也都能自己改（最多 100 字）。

| 項目 | 預設名稱 | 可以用的參數 |
|---|---|---|
| 直播狀態（直播中） | `🔴 直播中` | `{title}` 直播標題、`{game}` 直播分類（Twitch）、`{platform}` 正在直播的平台 |
| 直播狀態（沒有直播） | `⚫ 目前沒有直播` | |
| 總人數 | `👥 總人數：{members}` | 見下方 |
| 線上人數 | `🟢 線上：{online}` | 見下方 |
| 機器人數量 | `🤖 機器人：{bots}` | 見下方 |

人數頻道的名稱可以放：`{members}` 總人數、`{humans}` 成員人數（不含機器人）、`{online}` 線上人數、`{bots}` 機器人數量、`{boosts}` 加成次數。

* 直播狀態看的是伺服器[綁定的 Nekolive 創作者帳號](nekolive.md)，Twitch、YouTube、Kick 任一個在直播都算
* 可以選「沒有直播時隱藏頻道」，下播時頻道會整個藏起來

## 多久更新一次

* 直播狀態：開台、下播後 1 分鐘內更新，直播中改標題或分類也會跟著改
* 人數：大約每 5 分鐘更新一次

!!! info "名稱偶爾會晚幾分鐘才更新"
    Discord 限制頻道名稱 10 分鐘內只能改 2 次，短時間內反覆開台、下播或改標題時，名稱會等限制解除才跟上。

## 頻道的位置與刪除

* 頻道會開在伺服器最上面，開好後可以在 Discord 拖到想放的位置
* 關掉某一項或整個功能，機器人會刪掉它開的頻道，設定會保留
* 在 Discord 直接刪掉某個頻道，等於關掉那一項

機器人需要「管理頻道」權限；要在沒有直播時隱藏頻道的話，還需要「管理身分組」。
