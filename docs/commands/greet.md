# 成員進出訊息
> 指令：`/greet`  
> 權限需求：`管理伺服器 Manage Server`

有人加入、離開、被停權、被踢出時，機器人發一則你自訂的訊息到指定頻道；有人加入時，也可以另外私訊新成員一則。

每種訊息都可以只用純文字、只用 Embed 卡片，或兩個都用。

| 訊息 | 什麼時候發 | 發到哪裡 |
|---|---|---|
| 加入 | 有人加入伺服器 | 指定頻道 |
| 離開 | 成員自己離開伺服器 | 指定頻道 |
| 停權 | 有人被停權（封鎖） | 指定頻道 |
| 踢出 | 有人被踢出 | 指定頻道 |
| 加入私訊 | 有人加入伺服器 | 私訊新成員 |

## 總開關

功能本身要不要執行，是用 `/settings enable|disable member_messages` 控制（見[群組功能開關](settings.md)），預設為**啟用**。不過五種訊息預設都是**關閉**的，要各自打開才會發送。

## 編輯訊息內容

訊息的文字、Embed 與發送頻道，請到下面任一個地方編輯，兩邊改的是同一份設定：

* [網頁控制台](../dashboard.md) 的 **成員進出訊息**
* Nekolive 平台後台的 **Discord 機器人設定 → 模組設定 → 成員進出訊息**

編輯區右邊（手機在上方）有預覽，會用你自己的帳號與這個伺服器當範例，看起來就像在 Discord 裡的樣子。改完最慢 1 分鐘後生效。

## 指令

指令只做開關、查看與測試：

* `/greet status`：列出每種訊息的開關、發送頻道、內容種類（文字／Embed）
* `/greet toggle <event> <enabled>`：開啟或關閉某一種訊息
* `/greet test <event>`：用你自己當主角送一則測試訊息（「加入私訊」會私訊給你自己）

## 可以用的參數

文字、Embed 的標題、內容、欄位、頁尾都能放參數，點欄位後再點上面的參數就會插進去。網址欄位（作者圖示、縮圖、大圖、頁尾圖示）可以用 `{user_avatar}`、`{server_icon}`。

| 參數 | 內容 |
|---|---|
| `{user}` | 標記成員 |
| `{user_name}` | 使用者名稱 |
| `{user_display_name}` | 顯示名稱（有伺服器暱稱就用暱稱） |
| `{user_id}` | 使用者 ID |
| `{user_avatar}` | 成員頭像網址 |
| `{user_created}` | 帳號建立日期 |
| `{server}` | 伺服器名稱 |
| `{server_icon}` | 伺服器圖示網址 |
| `{member_count}` | 目前成員人數 |
| `{reason}` | 停權／踢出原因 |
| `{moderator}` | 執行停權／踢出的人（標記） |
| `{moderator_name}` | 執行停權／踢出的人（名稱） |

!!! info "標記不會吵到其他人"
    訊息裡只有被進出的那位成員會收到標記通知；就算內容寫了 `@everyone`、`@here` 也不會通知任何人。私訊完全不帶通知。

## 需要的權限

* 發送頻道：**檢視頻道**、**發送訊息**、**嵌入連結**。缺權限時那一則會跳過不發。
* 伺服器：**檢視審核日誌**。

!!! warning "沒有「檢視審核日誌」權限時"
    Discord 沒有「被踢出」這個事件，成員被踢出和自己離開，機器人收到的是同一個通知。機器人要讀審核日誌才分得出來，也才拿得到停權、踢出的原因與執行者。

    沒有這個權限的話：被踢出會發「離開」訊息、`{moderator}` 會顯示「（不明）」。`/greet status` 會提醒你缺這個權限；在 `/honeypot check` 按「🔄 重新邀請機器人」可以補上。

## 其他說明

* 停權也會讓成員離開伺服器，這時只會發「停權」，不會再多發一則「離開」。
* 「加入私訊」只發給真人帳號，機器人帳號加入不會收到。對方關閉了「允許來自伺服器成員的私訊」的話會送不到。
* 想記錄所有進出紀錄（而不是發歡迎訊息），請用[伺服器紀錄](serverlog.md)。
