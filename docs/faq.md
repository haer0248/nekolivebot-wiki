# 常見問題與疑難排解

!!! question "私訊通知一直收不到"
    檢查伺服器的隱私設定有沒有開啟「允許來自伺服器成員的私訊」（伺服器名稱旁下拉選單 → 隱私設定 → 私人訊息）。這個設定關著的話，機器人所有私訊通知都會被 Discord 直接擋掉，而且機器人不會出現任何錯誤，所以您不會知道通知漏發了。

!!! question "機器人無法管理某個成員"
    1. 檢查機器人有沒有「踢出、核准和拒絕成員」、「對成員停權」及「禁言成員」權限，或直接執行 `/honeypot check` 查詢目前的權限狀態。
    2. 機器人的身分組在 **伺服器設定 → 身分組** 清單裡的位階，有沒有比目標對象的身分組高。Discord 規定機器人只能對「身分組位階低於自己」的成員執行踢出、禁言、封鎖等操作，這跟權限開關無關，是平台規則，`/honeypot check` 也會列出目前哪些身分組還在機器人之上。

    如果對象是**伺服器擁有者**，那不管怎麼設定都不可能被踢、禁言、封鎖，這是 Discord 的規則，任何人（包含機器人）都做不到，不是機器人故障。

!!! question "`/honeypot check` 顯示缺權限怎麼辦"
    如果檢查發現權限不夠，檢查指令的回覆下面會有一顆「🔄 重新邀請機器人」按鈕，點下去會重新走一次 Discord 應用程式加入伺服器的流程，完成後會直接補齊機器人所有需要的權限，這樣就可以不用把機器人踢掉重邀一次。  

!!! question "洗版偵測／可疑帳號偵測誤判了真人成員怎麼辦"
    兩者都是機率性判斷，預設動作都是「不處理，只通知」，本來就是設計成先觀察、再視誤判率決定要不要調整處置力道。如果已經設定了自動處理但發生誤判：

    * 可疑帳號偵測可以用 `/accountcheck whitelist add` 把這個人加進白名單，之後他不會再被判斷
    * 洗版偵測目前沒有白名單機制，建議先把 `/antispam config` 的 `action` 調回「不處理」，或提高 `threshold`/`interval` 門檻

!!! question "加入入口頻道沒有開新頻道"
    1. 用 `/settings list` 確認「動態語音頻道」是啟用的
    2. 用 `/voice default status` 確認入口頻道有設定、而且還存在
    3. 同一個回覆裡會檢查機器人權限，動態語音頻道需要「管理頻道」、「管理身分組」與「移動成員」，缺哪一項會直接列出來

    如果你本來就有一個動態頻道還沒被刪，進入口只會被移回那個頻道，不會再開新的。

!!! question "動態頻道沒人了卻沒有被刪掉"
    機器人重新啟動或暫時斷線時，可能沒收到最後一個人離開的通知。重新上線後會在幾分鐘內自動檢查並補刪，不用手動處理；你自己把頻道刪掉也沒關係。
