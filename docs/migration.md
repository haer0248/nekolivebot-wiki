# 從舊機器人轉移

NekoliveBot#4325 接手了舊機器人 haer0248.me🍙#5792 的功能：公告頻道自動發佈、網址安全檢查、邀請連結偵測、自動討論串、自動懲處、私密轉送、動態語音頻道。

**以前有用舊機器人的伺服器，不用重新設定。**

## 會自動搬過來的東西

舊機器人的設定已經整理進 NekoliveBot 的資料庫。只要把 NekoliveBot 邀請進伺服器，機器人就會自動找出這個伺服器以前的設定並匯入，然後在歡迎私訊裡列出匯入了哪些項目。

| 舊機器人 | NekoliveBot |
|---|---|
| 公告自動發佈 | [公告頻道自動發佈](commands/publish.md) |
| 網址安全檢查 | [網址安全檢查](commands/urlsafety.md) |
| 自動建立討論串（頻道、標題、開頭訊息、冷卻） | [自動討論串](commands/autothread.md) |
| 自動懲處（動作、刪訊息、頻道警告、私訊擁有者、檢查機器人訊息） | [自動懲處](commands/autopunish.md) |
| 私密轉送（頻道、冷卻） | [私密轉送](commands/silent.md) |
| 動態語音（入口頻道、名稱、人數、私人、文字頻道） | [動態語音頻道](commands/voice.md) |
| 訊息紀錄＋紀錄頻道 | [伺服器紀錄](commands/serverlog.md) |

另外，舊機器人累積的邀請連結判定、假冒網域清單，已經直接併進 NekoliveBot 的全域資料，所有伺服器都會用到。

!!! note "舊機器人的「預設關閉」不會被搬過來"
    舊機器人會把整份預設值存進每個伺服器，所以分不出「管理員關掉的」和「從來沒開過的」。公告自動發佈、網址安全檢查、自動討論串、動態語音這四個開關，舊設定是關閉的話就不搬，改用 NekoliveBot 自己的預設值（公告自動發佈預設開啟；自動討論串、動態語音要設定頻道才會有作用）。  
    自動懲處在舊機器人預設就是開啟、動作是封鎖，這是這些伺服器一直以來的實際行為，所以照搬。想改成禁言可以用 `/autopunish config`。

!!! info "不會蓋掉你已經改過的設定"
    匯入時只會補上「還沒設定過」的項目。如果你已經在 NekoliveBot 或平台後台調整過某個功能，那個功能會保留你現在的設定。  
    舊設定裡的頻道如果已經被刪掉，那一項會略過，歡迎私訊裡會列出來。

## NekoliveBot 已經在伺服器裡了？

如果 NekoliveBot 早就在你的伺服器，不會自動匯入（機器人只在被邀請進來的當下檢查）。請執行：

* `/settings import-legacy`：匯入舊機器人在這個伺服器的設定
* `/settings import-legacy again:True`：已經匯入過，想再跑一次（一樣不會蓋掉現有設定）

## 匯入完記得把舊機器人踢掉

兩隻機器人同時在伺服器裡的話，自動發佈、自動討論串、動態語音這些功能會重複動作（例如同一則訊息開兩個討論串）。確認 NekoliveBot 運作正常後，請把舊機器人踢出伺服器。
