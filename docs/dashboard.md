# 網頁控制台

除了用指令，也可以在網頁上調整 NekoliveBot 的設定。網頁控制台跟創作者斗內平台是分開的，不需要平台帳號，用 Discord 帳號登入就可以。

**[bot.nekolive.net](https://bot.nekolive.net/){:target="_blank"}**

## 可以做什麼

* 開關每一項功能，調整各功能的細節設定（跟對應的 `config` 指令是同一份設定，改哪邊都一樣）
* 頻道、身分組都用下拉選單選，不用自己找 ID
* 查詢紀錄：機器人的自動處理結果、伺服器紀錄（成員進出、訊息編輯刪除、語音進出）、公告發佈失敗與私密轉送紀錄
* 伺服器備份：預覽備份內容、手動備份、還原
* 建立、編輯、發佈身分組領取面板
* 設定機器人在這個伺服器的暱稱與大頭貼

## 誰可以用

登入後只會列出你有 **「管理伺服器」** 權限的伺服器（擁有者與有「管理員」權限的人也算）。機器人還沒加入的伺服器，旁邊會有邀請按鈕。

在 Discord 上被拿掉權限的話，最慢 5 分鐘後網頁控制台就不能再改那個伺服器。

!!! info "登入會讀取哪些資料"
    只會讀你的 Discord 名稱、大頭貼，以及你所在的伺服器清單（用來判斷權限），不會讀取或發送任何訊息。

## 設定多久生效

功能開關最慢 30 秒、其他設定最慢 1 分鐘後生效（機器人會短暫快取設定，避免每則訊息都查一次資料庫）。
