# 11/08 更新紀錄

機器人也能發 Twitch 開台通知了！用 `/livenotify add` 加一個頻道，開台時機器人就會在 Discord 通知大家，下播後也可以自動把通知刪掉。

<!-- more -->

## 新增

- [Twitch 開台通知](../../commands/livenotify.md)（`/livenotify`）
    - 每個伺服器最多 25 個，任何 Twitch 頻道都可以，同一個頻道也能通知到不同的頻道
    - 可以只通知，也可以設定下播後自動刪除通知；中途斷線很快重新開台不會重發
    - 通知的文字、按鈕文字和 Embed 在[網頁控制台](../../dashboard.md)修改，有即時預覽，也可以送測試通知
    - 訊息文字輸入 @ 就能選要標記的身分組
- [動態語音頻道](../../commands/voice.md)多了設定面板
    - 頻道開好之後會在聊天室發一個面板，改名、人數上限、公開或私人、邀請、踢出、轉移擁有者、關閉頻道按按鈕就能設定，不用再打指令
    - 新增「鎖定」：大家看得到頻道，但只有被邀請的人能加入
    - 新增「認領頻道」：擁有者先離開的話，留下來的人可以接手
    - 新增「頻道管理員」：擁有者可以找最多 5 個人幫忙改名、邀請或踢出成員，轉移擁有者和關閉頻道還是只有擁有者能做
    - 不想自動發面板的話，管理員可以用 `/voice default panel` 或在網頁控制台關掉，擁有者還是可以用 `/voice panel` 叫出來
- 網頁控制台的紀錄多了「權限問題」
    - 機器人在哪個頻道權限不夠、少了哪些權限，都會記在這裡，同一個頻道只記一筆
    - 權限是夠的但還是做不到（例如身分組順序太低）的話，也會說明要怎麼調整
