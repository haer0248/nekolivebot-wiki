# 11/02 更新紀錄

伺服器紀錄的成員加入卡片多了操作按鈕，有人大量加入時可以直接踢出、停權或禁言。社交媒體預覽可以選擇要轉換哪些平台。

<!-- more -->

## 新增

- [伺服器紀錄](../../commands/serverlog.md)的成員加入卡片
    - 固定顯示對方的顯示名稱與使用者名稱，對方離開後也看得出是誰
    - 卡片下方有「取得 ID」「踢出」「停權」「禁言」按鈕，處理完會顯示是誰做了什麼
- [社交媒體預覽](../../commands/twitter.md)可以分別開關 Twitter／X、Instagram、Threads、Facebook，預設四個都開，以前開過的伺服器不用重新設定
