# 10/08 更新紀錄

新增成員進出訊息：有人加入、離開、被停權、被踢出時，發一則你自訂的訊息。直播通知的 Webhook 也可以直接在網頁上建立了。

<!-- more -->

## 新增

- [成員進出訊息](../../commands/greet.md) (`/greet`)：加入、離開、停權、踢出各自一則訊息，加入時也可以另外私訊新成員
    - 每種訊息可以只用純文字、只用 Embed 卡片，或兩個都用，發送頻道各自設定
    - 文字與 Embed 都能放參數，例如 `{user}`、`{server}`、`{member_count}`、停權／踢出的 `{reason}`、`{moderator}`
    - 內容在[網頁控制台](../../dashboard.md)或平台後台「模組設定 → 成員進出訊息」編輯，旁邊有預覽；指令只做開關（`/greet toggle`）、查看（`/greet status`）與測試（`/greet test`）
    - 五種訊息預設都是關的，要各自打開
- [建立 Webhook](../../commands/webhook.md) 不用再下指令了：平台的直播通知、影片上傳通知頁，Webhook 網址欄位旁多了「建立 Webhook」按鈕，選頻道就自動填好；[網頁控制台](../../dashboard.md)也多了「建立 Webhook」頁

- [伺服器紀錄](../../commands/serverlog.md)多了「身分組變更」：成員被加上或拿掉身分組時記一筆，會寫是誰操作的（`/serverlog config member_role:True`，預設開啟）

- [私密轉送](../../commands/silent.md)可以附圖片，匿名訊息下方多了「發送訊息」按鈕；管理員可以改顯示樣式（Embed 卡片或純文字）、卡片內容、字數上限、能不能附圖片，還有 `{number}` 投稿編號

## 調整

- 平台後台的頻道改成直接點選（成員進出訊息、伺服器紀錄、建立 Webhook），不用再自己找頻道 ID

- `/webhook channel` 在頻道裡已經有機器人建立的 Webhook 時會直接沿用，不會每次都多一個；要換新網址加上 `new:True`
- 機器人需要的權限多了「檢視審核日誌」，用來分辨踢出與自己離開，以及拿到停權、踢出的原因與執行者
    - 已經在伺服器裡的機器人，可以在 `/honeypot check` 按「🔄 重新邀請機器人」補上權限，不用把機器人踢掉
