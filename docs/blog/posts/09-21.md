# 09/21 更新紀錄

這次補的是「被盜帳號或惡意機器人進來亂」的兩個情境：一個是攔在事情發生前，一個是收拾殘局。

<!-- more -->

## 新增

- 新增了大量標記偵測 (`/mentionguard`)：抓沒有管理伺服器權限的人觸發 @everyone 或 @here，或一次標記大量身分組、成員。
- 新增了伺服器結構備份 (`/backup`)：備份類別、頻道與身分組，可在結構被惡意刪掉之後還原。
    - 偵測到頻道或身分組被刪除時，會自動保存一份**刪除前**的結構快照
    - 注意：訊息內容沒辦法備份，這是 Discord 的限制
- 平台後台的「Discord 機器人設定」加上這兩個功能的設定分頁，備份可以直接在網頁上建立、預覽內容與還原

## 其他

- 機器人大頭貼現在可以直接從平台的檔案空間挑圖，存檔時會透過 Discord 官方 API 即時套用
